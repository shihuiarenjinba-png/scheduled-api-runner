# Scheduled API Runner — Privacy Policy

Status: Store preparation text. Public hosting URL can be assigned later if the submission form requires it.

Scheduled API Runner is a Windows desktop application that runs user-configured HTTPS API requests and can save selected response data to local files such as JSON, text, Excel, or dated CSV history.

The app may process API endpoint URLs and host names, user-created job names and schedules, selected fields, local file paths, API response data, local execution state, and environment-variable references used to obtain credentials at runtime. The application is designed not to display authentication header values or secret values in its normal UI or audit logs.

Network requests are sent only after the user configures and approves live execution. Requests are restricted to configured HTTPS hosts. Offline Dry Run and configuration preview do not send the configured API request.

The app does not provide a hosted cloud service. Configuration files, execution state, logs, exported data, CSV history, and backups remain on the user's Windows device unless the user moves or deletes them.

Users are responsible for having permission to access configured APIs and for handling returned data according to the API provider's terms and applicable law.

Removing an optional Windows scheduled task does not delete the user's configuration or data files.
